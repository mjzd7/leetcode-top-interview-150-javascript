Fixing the Icon + Wordmark Lockup

The earlier 3-slab keystone had three visual problems as soon as the word Invariant was placed beside it (and earlier badge options tried to cram letters inside a box):

  • 1. Looked like a UI "Filter / Sort" button: Three shrinking horizontal bars trapped inside a faint bordered box reads as a table filter control, not a brand identity.
  • 2. Washed-out opacity & dead space beside I: The 38%-opacity top slab vanished into the background box, while the narrow bottom left an awkward diagonal gap next to the vertical stem of I.
  • 3. Zero color bridge to the text: A 100% green icon inside a green border felt detached from the white wordmark. By removing the weak border box and adding a crisp secondary facet in the exact wordmark color (--fg), the symbol and text fuse into one cohesive lockup.
