Exhaustive Architectural Topology & 6-Layer Architecture

The system is decomposed into six tightly decoupled subsystems designed for sub-millisecond execution, zero-trust edge boundaries, and fail-closed integrity:

1. Client Presentation Tier

Zero-framework vanilla SPA (docs/index.html). 56px inset glass header, 240Hz semi-implicit Euler spring cursor, and container-bounded delta scroll arithmetic.

2. Online Judge & Polyglot Drivers

api/judge/run.mjs executing five exact codecs (json, tree, list, graph, ops). Defends against stdout bombs, console clobbering, and memory overflows.

3. Stateless Auth & SESSION_EPOCH

GitHub OAuth 2.0 with HMAC-SHA256 session cookies. Features the SESSION_EPOCH global kill-switch for instant token invalidation with zero database lookups.

4. Edge AI Streaming & Abuse Defense

Vercel Edge streaming SSE proxy with 10s keepalive heartbeats, 52s total budget ceiling, Upstash Redis multi-tier rate limiting (5/min IP vs 20/min Auth), and two-channel delimiter fencing.

5. AST Dry-Run & QuickJS WASM Sandbox

Offline Acorn AST probe injection using static regionTable offsets. Emits Envelope v1.1 traces with in-realm Map/Set/BigInt serializers inside a 3s/16MB QuickJS WASM realm.

6. Verification & Quality Gates

SHA-256 script digest enforcement in vercel.json, 471 chat assertions, 96 judge assertions, and Playwright recursive ancestor luminance contrast scans.

15 Architectural & Technical Decision Records (ADRs)

Immutable Engineering Decisions, Root Causes & Rationale
DEC-01 UI / Vector Injected SVG Vector Geometry vs. DOM Border-Radius Cursors
▼
Problem Statement & Root Cause
When custom cursors use traditional HTML <div> elements with border-radius: 50% and CSS transforms, browser GPU compositors (Chromium Skia / WebKit CoreAnimation) isolate the element into a dedicated texture layer (cc::PictureLayer) rasterized once at base layout dimensions (32×32px). During page zoom (150%, 200%) or interactive scale pop (2.227×), the GPU fragment shader executes an affine matrix stretch on the low-res raster texture quad, producing severe bilinear blur, pixelation, and staircase artifacts.
Rejected Alternatives
1. High-Resolution Oversized Divs (e.g. 256×256px scaled down): Wasted GPU texture memory and created subpixel shimmering during slow pointer drift.
2. Fullscreen HTML5 Canvas Layer: Required full-viewport compositing passes every frame, draining battery life and degrading scroll frame rates.
Adopted Architecture
Structured #cur-dot and #cur-ring with inline <svg> and <circle> elements. Enforced shape-rendering="geometricPrecision" for native analytic trigonometric curve anti-aliasing. Enforced vector-effect="non-scaling-stroke" on the lens ring to maintain an invariant 1.0px hairline stroke at any scale.
DEC-02 Physics / Math 240Hz Semi-Implicit Euler Dynamic Spring Physics
▼
Problem Statement & Root Cause
Standard LERP followers lack mass and momentum, feeling sluggish at high speeds and drifting during slow adjustments. Explicit Euler integrators suffer from catastrophic numerical instability at high display refresh rates (120Hz/240Hz ProMotion displays) or during frametime hiccups, causing position values to diverge to infinity.
Mathematical Formulation & Adopted Integrator
F_spring = -k * (x - x_target)
F_damping = -c * v
a = F_spring + F_damping
v_{t + Δt} = v_t + a * Δt
x_{t + Δt} = x_t + v_{t + Δt} * Δt
Constants deployed: Trailing Ring: k = 190, c = 17 (fluid, organic, critically damped trailing); Center Dot: k = 1400, c = 60 (instantaneous tactile magnetic snap); Scale Pop: k = 240, c = 20. Includes an automatic mechanical energy sleep gate (E = ½kΔx² + ½mv² < ε) that pauses requestAnimationFrame when resting (0.00% idle CPU).
DEC-03 Ergonomics Hybrid Pointer Gating & Universal OS Cursor Suppression
▼
Problem Statement
Tablets and touchscreen laptops report pointer: coarse, causing CSS media queries to suppress custom cursors even when an external mouse or Magic Keyboard trackpad is actively controlling the device. Conversely, tapping the touch screen dispatches touch coordinates, leaving an "orphaned cursor dot" frozen in place. In addition, Tailwind CSS preflight rules (button { cursor: pointer; }) override container-level cursor: none, leaking the OS hand cursor.
Adopted Architecture
Dynamic event inspection: checks e.pointerType === 'touch' on every pointer event. Touching instantly hides the custom cursor and skips physics calculation. Deployed universal descendant suppression:
@media (hover: hover) and (pointer: fine) {
  html[data-cursor="on"], html[data-cursor="on"] * { cursor: none !important; }
}
Over editable fields, the ring morphs into an SVG-free double-serif I-beam caret with spring constants switching to k = 1400, c = 60.
DEC-04 Geometry Precision 3-Tier Snapping & Mathematical Quadrant Partitioning
▼
Problem Statement
Centering the cursor ring directly over buttons and chips (targetX = left + width / 2) obscures the label text inside the button. Furthermore, snapping over inline hyperlinks in body text disorients readers and breaks reading flow.
Adopted Geometry
1. Action Controls (Exact Corner Snapping): Pinned to top-right vertex (targetX = rect.right, targetY = rect.top). Because the interior of the element occupies exactly one 90° quadrant (180° ≤ θ ≤ 270°), exactly 25% of the circle is inside and 75% is outside, providing zero text occlusion.
2. Sidebar Nav Items: Pinned to vertical midpoint of right border, bisecting the circle 50% / 50% to mirror the left indicator.
3. Inline Links & Badges: Suppresses snap ring entirely (opacity: 0), scales center dot 1.6× with drop-shadow glow, and activates a 1.5px underline with 3px offset.
DEC-05 Judge / Codecs Polyglot Codec Registry: Hard Rule G1 vs. Lazy Fallbacks
▼
Problem Statement & Silent-Wrong Risk
In an algorithmic judge testing 150 diverse LeetCode problems, data structures vary widely: arrays/primitives (101), binary trees (20), linked lists (13), connected graphs (9), and stateful design classes (7). If an unrecognised structure falls back lazily to JSON.stringify, cyclic graphs trigger fatal runtime crashes, while functions returning scalar numbers (e.g. maxDepth(root) = 3) encoded with a default tree codec output [null], resulting in the worst failure mode: silent-wrong execution traces.
Adopted Architecture (Hard Rule G1)
Implemented exactly five codecs in api/_lib/codecs.mjs (json, tree, list, graph, ops). Hard Rule G1 strictly forbids default branches, lazy passthroughs, or fallbacks. Querying an unlisted codec throws CodecNotImplementedError immediately, failing CI loudly. Exotic values (undefined, NaN, ±Infinity, -0, BigInt, Map/Set, typed arrays) and cyclic graphs are handled via back-references ({__ref: N}) in scripts/lib/serialize.mjs.
DEC-06 Auth / Sec Stateless Authentication & The Zero-Database SESSION_EPOCH Kill-Switch
▼
Problem Statement & Incident Response Defect
Stateless signed session cookies last 30 days to avoid constant re-authentication. However, if a signing secret or cookie is compromised, traditional stateless architectures have zero revocation mechanisms without standing up a centralized database blacklist, completely destroying edge speed.
Adopted Architecture (SESSION_EPOCH)
In api/_lib/session.mjs, every session token embeds { githubId, login, epoch, iat, exp } signed with HMAC-SHA256. The server checks epoch === sessionEpoch() on every invocation. In an incident, updating the environment variable SESSION_EPOCH=2 instantly invalidates all outstanding cookies across all global edge instances simultaneously, with zero database queries and zero storage overhead. Malformed epochs safely fall back to default epoch 1 rather than logging everyone out.
DEC-07 Rate Limiting Multi-Tier Rate Limiting & The NAT Collusion Defense
▼
Problem Statement
Relying purely on IP-based rate limiting (5 req/min) punishes users behind shared NAT gateways (university campuses, corporate offices, mobile cell towers), causing collective denial of service. Conversely, attackers rotating IP addresses can easily bypass per-IP limits.
Adopted Architecture
Implemented tiered quotas via Upstash Redis sliding window:
  • Anonymous Callers: Capped at 5 req/min per IP.
  • Authenticated Callers: Authenticating via GitHub elevates the user to 20 req/min attached to their immutable GitHub ID (chat:u:<githubId>), decoupling them from NAT IP contention.
  • Daily IP Ceiling: Enforces an absolute 300 req/day per IP cap across both anonymous and authenticated traffic, ensuring total OpenAI budget protection.
DEC-08 Security / AI Two-Channel Delimiter Fencing Against Prompt Injection
▼
Problem Statement
When the AI model fetches external web documentation (via Firecrawl) or receives client page context, untrusted text could contain prompt injections instructing the model to ignore safety constraints, exfiltrate API keys, or impersonate system actors. Naive keyword scrubbing corrupts legitimate JavaScript code containing object literals like { system: 'prod' }.
Adopted Architecture
Deployed strict boundary fencing with distinct delimiter channels:
Page Context: <<<GUIDE_CONTENT>>> ... <<<END_GUIDE_CONTENT>>>
Tool Content: <<<TOOL_CONTENT>>> ... <<<END_TOOL_CONTENT>>>
System prompts explicitly instruct the model that content within tool fences is unverified data and must never be interpreted as instructions. Page context never enters the history array, preventing user prompt replay attacks.
DEC-09 Data Scale Monolithic curriculum-data.js (3.09 MB) vs. Dynamic REST Chunking
▼
Problem Statement & The 65MB Scale Wall
Should the 150 LeetCode guides be loaded on demand via individual HTTP requests or bundled into a single static payload? While dynamic loading saves initial bandwidth, network latency ruins instant client-side search across 450 dry-run tables. However, bundling all 3,400 LeetCode problems would create a catastrophic ~65 MB payload.
Adopted Architecture
For the curated LeetCode 150 curriculum, scripts/build-site.mjs compiles all guides into a monolithic 3.09 MB docs/curriculum-data.js. Served with aggressive HTTP caching and Gzip/Brotli compression (compressed to ~680 KB), this delivers zero-latency offline navigation and sub-5ms client-side fuzzy searching across the entire curriculum. Expansion beyond 150 is gated to dynamic edge routes.
DEC-10 AST / Dry-Run Dry-Run AST Instrumentation: The Depth-Counter Fallacy
▼
Problem Statement & The Fatal Flaw
Earlier prototypes used a runtime call-depth counter (depth++ on enter, depth-- on exit) to isolate top-level function invocations. The Fatal Flaw: 102 of the 450 LeetCode solutions are self-recursive algorithms. A runtime counter tagged the first call as depth 0 and treated all recursive calls as depth > 0, silently suppressing the entire recursive call tree and emitting empty 1-frame traces that falsely passed naive assertion tests.
Adopted Architecture
Abolished runtime depth inference completely. scripts/gen-blocks.mjs compiles an immutable static regionTable in build/blocks.json. Acorn probes are injected by exact character source slices, referencing the static region table. Enforced Rule V11 non-vacuity gates requiring ≥ 3 frames for recursive algorithms.
DEC-11 Edge / Stream Edge AI Streaming: Reflow Containment & Wall-Clock Headroom
▼
Problem Statement
Parsing Markdown, KaTeX, and Mermaid per SSE chunk causes extreme browser layout thrashing. Concurrently, Vercel Edge functions enforce a strict 60-second execution ceiling. Long-running model tool calls trigger reverse proxy disconnections and 504 gateway timeouts.
Adopted Architecture
1. stableSplit() Dual-Buffer Reveal: Separates settled text (up to the last completed paragraph outside code fences) from the live tail. settled markdown is parsed once (paintReveal()), while the live tail streams into raw textContent at 60fps.
2. 52-Second Total Budget (TOTAL_BUDGET_MS = 52s): Leaves 8 seconds of execution headroom to synthesize an error frame.
3. 10s SSE Keepalives: Emits : ping\n\n comments every 10s to keep HTTP proxies alive.
4. 15s Tool Budget Guard: Verifies ≥ 15s remain before invoking web search; otherwise falls back to prose generation.
DEC-12 Security / CSP Cryptographic Content Security Policy (CSP) Invariants
▼
Problem Statement
SPAs often resort to 'unsafe-inline' to avoid Dark Mode flash-of-unstyled-content (FOUC). This violates security requirements and creates XSS exposure.
Adopted Architecture
vercel.json strictly forbids 'unsafe-inline' for scripts. Pinned exactly 2 inline script blocks in docs/index.html. Synchronized via scripts/refresh-csp-hash.mjs, which calculates SHA-256 base64 digests and updates deployment manifests. Playwright tests fail closed if an unhashed script tag is introduced.
DEC-13 Layout Layout Invariants: Inset Box-Shadow vs. Border-Bottom (56px Rule)
▼
Problem Statement
Adding border-bottom: 1px solid var(--border-soft) to the frosted glass header increased its computed height from 56px to 57px in Chromium. This 1px deviation broke fixed viewport height computations across mobile drawer overlays and caused subpixel layout jitter during scrolling.
Adopted Architecture
Replaced exterior borders with an inset box shadow:
box-shadow: inset 0 -1px 0 var(--border-soft) !important;
Preserves the exact 56px layout invariant with zero box-model reflow.
DEC-14 Storage / KV Idempotent User Progress & Capped Prediction Event Buffer
▼
Problem Statement
Tracking user problem passes and dry-run prediction telemetry in Upstash KV can cause unbounded array growth, degrading read latency and hitting KV storage limits. Furthermore, network outages during progress saves must never block judge verdict delivery.
Adopted Architecture
In api/_lib/kv.mjs, solved progress writes are strictly deduplicated sets (idempotent). Telemetry events are stored in a dedicated key space capped at exactly 500 events using a FIFO drop queue. In case of Upstash KV network failure, the functions degrade gracefully to empty progress without failing code execution verdicts or throwing client-side exceptions.
DEC-15 Visualizers Custom Domain Visualizers (viz-array / viz-tree) vs. Generic Mermaid
▼
Problem Statement
Mermaid diagrams are ideal for flowcharts and sequences, but rendering two-pointer array indices (e.g. L, R, write) or binary tree node traversals using generic Mermaid nodes is visually cluttered, slow to parse, and cannot animate dynamically during dry-run step stepping.
Adopted Architecture
Engineered custom lightweight JSON-driven visualization blocks (~~~viz-array, ~~~viz-tree, ~~~viz-matrix) embedded directly in the curriculum markdown. The client renders memory cells with dedicated pointer badges (e.g. p=0, L, R) at sub-millisecond speeds, fully integrated with theme CSS variables.

Engineering Management Playbook: 7 Strict Rules

Inviolable Operational Invariants & Governance Principles
Rule 01
The "Phantom Problem" Fallacy
Engineers frequently draft complex refactoring proposals based on memory or impression. During the chatbox hardening initiative, a plan proposed rewriting saveStore() to add persistence. Verification revealed saveStore() did not exist because persistence was already implemented and fully covered by tests under STORAGE_KEY = 'lt150-chat-v1'.
Governance Rule: Never approve a refactoring proposal without verifying line numbers and running tests against the active tree first.
Rule 02
The "Vacuous Test" Illusion
A 100% passing test suite can be completely hollow. In early dry-run engine prototypes, tests asserted that traces were produced. The test suite passed green, yet 102 recursive solutions emitted empty traces containing only the root frame because a runtime depth counter silently suppressed recursive calls.
Governance Rule: Assertions must verify payload substance (e.g. Rule V11 non-vacuity). Periodically inject faulty inputs to test the test oracle.
Rule 03
Serverless Time-Budget Defense
Vercel Edge Functions terminate abruptly at 60s without throwing catchable exceptions. Allowing an AI model to invoke multiple external search tool calls can consume 50s, leaving no time to stream prose answers back to the user before an HTTP 504 error.
Governance Rule: Set a strict 52s global route budget, emit 10s keepalives, and require a 15s tool reserve before dispatching external calls.
Rule 04
Recursive Contrast Resolution
Automated accessibility tests attempting to compute text contrast via getComputedStyle().backgroundColor return rgba(0,0,0,0) (transparent) on unstyled card containers. Parsing this as black produced hundreds of false test failures for dark text over white cards.
Governance Rule: Contrast computation utilities must walk up the DOM ancestor tree until resolving an opaque background layer before calculating luminance.
Rule 05
Layout Invariant Discipline
Adding a standard 1px border to the frosted glass header increased outer height from 56px to 57px, breaking mobile drawer positioning and causing subpixel scrolling jitter. Replacing exterior borders with inset box shadows preserved the 56px invariant.
Governance Rule: Use inset box shadows for hairline container dividers and enforce rigid height invariants with automated viewport tests.
Rule 06
Zero-Database Incident Response
Stateless session architectures are often crippled during security incidents because revoking leaked tokens usually requires retrofitting a database blacklist. By embedding an integer epoch into every signed token, revoking all outstanding tokens is a one-line environment variable bump.
Governance Rule: Build global cryptographic kill-switches into stateless protocols at inception to enable instantaneous zero-database incident mitigation.
Rule 07
The Danger of Lazy Fallbacks
In data-intensive pipelines like algorithmic execution judges, developers often add lazy fallback branches (e.g. defaulting unrecognised structures to JSON). This produces "silent-wrong" data that looks plausible but corrupts execution trees.
Governance Rule: Enforce strict codec registries without fallbacks (Hard Rule G1). Codecs must fail loudly at build time rather than emitting corrupted runtime data.
