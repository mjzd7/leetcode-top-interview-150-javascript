3. Comprehensive Edge Cases & Failure Modes

The following 12 edge cases must be explicitly coded and verified in the automated suite:

  1. Virtual Keyboard on Mobile (VisualViewport Push): When focusing #ltcInput on iOS/Android, the virtual keyboard takes 40–50% of the screen. Solution: In mobile modes, subscribe to window.visualViewport.addEventListener('resize', ...). When visualViewport.height < window.innerHeight, clamp panel height to visualViewport.height and scroll composer into view.
  2. Orientation Change (Portrait ↔ Landscape): User rotates phone from 390×844 to 844×390 while chat is open. Solution: window.addEventListener('resize') detects innerHeight ≤ 500. If previously in snap-bottom, automatically switch to pinned-right side-card mode. If rotating back to portrait, restore previous portrait height.
  3. Window Resized Smaller Than Float Rect: User floats chat to (x: 1000, y: 300) on a 1920px screen, then resizes window to 1100px. Solution: Window resize hook runs clampFloatPosition(): if x + width > innerWidth - 8, set x = Math.max(8, innerWidth - width - 8).
  4. Streaming Response In-Flight During Mode Switch: SSE tokens arriving while user drags, pins, or fullscreens the panel. Solution: Reparenting is performed via container.appendChild(el.panel). In the DOM specification, moving an attached node via appendChild retains all in-memory event listeners, timers, closures, and SSE stream connections. No stream reconnection needed.
  5. Wide Markdown Tables & Mermaid Diagrams: AI emits a 6-column markdown table or wide Mermaid graph that exceeds the 380px panel width. Solution: All table and mermaid containers are wrapped in .ltc-table-scroll with overflow-x: auto; max-width: 100%;. Panel width must NEVER stretch horizontally due to child content.
  6. Escape Key Hierarchy: Pressing Esc when multiple overlays coexist. Solution: 1. If Command Palette (#paletteOverlay, z-50) is open → Palette handles Esc. 2. If Chat is Fullscreen (z-44) → Chat exits fullscreen, restores float/dock rect. 3. If Chat is Modal Sheet (<1280px with backdrop open) → Chat closes to FAB. 4. If Chat is Floating (non-modal) → Esc minimizes chat to FAB, preserving thread in memory, and returns focus to last active document element.
  7. Focus Trap Containment: Only trap focus with Tab navigation when in modal sheet mode with backdrop. NEVER trap focus in floating or docked mode, allowing the user to seamlessly click code blocks in the article while keeping the chat open.
  8. Off-Screen / Multi-Monitor Drag Clamping: During pointer dragging, clamp the cursor math so the panel header cannot be moved above y = 56px (below top navigation bar) or dragged off the bottom/sides. Minimum visible area guaranteed: 100% of header visible.
  9. Rapid Toggling / Double-Click Debouncing: Rapid clicking of pin/fullscreen/dock buttons. Solution: All mode switches execute synchronously with CSS transitions disabled during instant layout calculations to prevent transition stack-up.
  10. FAB vs Send Button Collision (The L-7 Rule): Under NO circumstances may the FAB dot float above or overlap the composer Send/Stop button. Solution: Whenever #ltcPanel is visible (in docked, floating, pinned, or sheet mode), #ltcFab has class is-tucked (opacity: 0, pointer-events: none). FAB only appears when chat is minimized.
  11. Double-Click Header to Maximize / Restore: Double-clicking .ltc-head in floating mode toggles between current float rect and fullscreen mode.
  12. Accessibility & ARIA Attributes: Update aria-expanded on FAB, aria-hidden on panel when closed, role="complementary", and aria-modal="true" ONLY when backdrop is active.

4.3. JavaScript Geometry Engine & Controller (docs/chat-widget.js)

/* --- Configuration & Storage Constants --- */
var RECT_KEY = 'lt150-chat-rect';
var MODE_KEY = 'lt150-chat-mode';
var MIN_W = 320;
var MAX_W = 900;
var MIN_H = 200;
var TOP_NAV_H = 56;

// State extensions
state.mode = 'docked'; // 'docked' | 'floating' | 'pinned-right' | 'snap-bottom' | 'fullscreen'
state.floatRect = { x: 800, y: 80, w: 420, h: 560 };
state.snapStep = '40dvh'; // '40dvh' | '90dvh'

/** Deterministic breakpoint detection */
function isDesktop() {
  return window.matchMedia('(min-width: 1280px)').matches;
}
function isLandscapeShort() {
  return window.innerHeight <= 500;
}

/** Pure clamping math function */
function clampFloatRect(rect) {
  var vw = window.innerWidth;
  var vh = window.innerHeight;
  var w = Math.min(Math.max(rect.w, MIN_W), Math.min(MAX_W, vw - 16));
  var h = Math.min(Math.max(rect.h, MIN_H), vh - TOP_NAV_H - 16);
  var x = Math.min(Math.max(rect.x, 8), Math.max(8, vw - w - 8));
  var y = Math.min(Math.max(rect.y, TOP_NAV_H + 8), Math.max(TOP_NAV_H + 8, vh - h - 8));
  return { x: Math.round(x), y: Math.round(y), w: Math.round(w), h: Math.round(h) };
}

/** Mount panel to appropriate container node without destroying DOM state */
function mountPanel(mode) {
  var overlay = $('ltcOverlay');
  var rail = $('ltRail');
  if (mode === 'docked') {
    if (el.panel.parentElement !== rail) {
      rail.appendChild(el.panel);
    }
    rail.removeAttribute('data-collapsed');
  } else {
    if (el.panel.parentElement !== overlay) {
      overlay.appendChild(el.panel);
    }
    if (isDesktop()) {
      rail.setAttribute('data-collapsed', 'true');
    }
  }
}

/** Set and apply a layout mode */
function setMode(newMode, persist) {
  state.mode = newMode;
  el.panel.setAttribute('data-mode', newMode);
  mountPanel(newMode);

  if (newMode === 'floating') {
    state.floatRect = clampFloatRect(state.floatRect);
    el.panel.style.setProperty('--ltc-x', state.floatRect.x + 'px');
    el.panel.style.setProperty('--ltc-y', state.floatRect.y + 'px');
    el.panel.style.setProperty('--ltc-w', state.floatRect.w + 'px');
    el.panel.style.setProperty('--ltc-h', state.floatRect.h + 'px');
  } else if (newMode === 'pinned-right') {
    el.panel.style.setProperty('--ltc-w', Math.min(480, Math.max(320, state.floatRect.w)) + 'px');
  } else if (newMode === 'snap-bottom') {
    el.panel.setAttribute('data-snap-step', state.snapStep);
  }

  // Update backdrop: active ONLY for modal sheet (<1280px snap-bottom 90dvh)
  if (el.backdrop) {
    if (newMode === 'snap-bottom' && state.snapStep === '90dvh') {
      el.backdrop.classList.add('is-open');
    } else {
      el.backdrop.classList.remove('is-open');
    }
  }

  if (persist) {
    try {
      localStorage.setItem(MODE_KEY, newMode);
      localStorage.setItem(RECT_KEY, JSON.stringify(state.floatRect));
    } catch (e) {}
  }
}
